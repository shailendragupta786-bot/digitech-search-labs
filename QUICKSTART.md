# 🚀 Quick Start Guide

## First Time Setup

```bash
cd ~/Projects/digitech-search-labs
npm install
```

## Development

```bash
npm run dev
```

Opens http://localhost:3000 with hot reload. Edit any file and changes appear instantly.

## Build for Production

```bash
npm run build
```

Creates optimized `dist/` folder (184 KB total, ~56 KB gzipped).

## Preview Production Build

```bash
npm run preview
```

Test the production build locally before deploying.

## Lint Code

```bash
npm run lint
```

## Key Commands Summary

| Command | Purpose |
|---------|---------|
| `npm run dev` | Start dev server with HMR |
| `npm run build` | Build for production |
| `npm run preview` | Serve production build locally |
| `npm run lint` | Run ESLint |

~/Projects/digitech-search-labs/

## Components Quick Reference

- **Header**: Logo, nav, mobile menu
- **Hero**: Headline, CTAs, trust bar
- **EngineeringAdvantage**: Comparison grid
- **Disciplines**: 4 service cards
- **CaseStudy**: Client case breakdown
- **AuditForm**: 5-field form + contact sidebar
- **FloatingWhatsApp**: Bottom-right button
- **JsonLd**: Schema.org structured data

## Colors

- **Navy**: `#0F172A` (bg)
- **Crimson**: `#DC2626` (accent)
- **White**: Text

## Deployment

### Vercel (Best)
```bash
git push origin main
# Vercel auto-builds and deploys
```

### Manual
```bash
npm run build
# Upload dist/ to web host
```
